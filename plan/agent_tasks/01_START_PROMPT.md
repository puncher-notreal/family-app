# Первый промпт для Codex / другого coding-агента

Ты участвуешь в разработке мобильного приложения для родителей и детей 7–12 лет. В репозитории лежит проектная документация, включая `AGENTS.md`, `README.md`, `docs/*` и `db/001_schema_draft.sql`.

**Текущая задача: P0-01 и подготовка к P0-03. Пока не писать бизнес-код и не подключать платную инфраструктуру.**

1. Прочитай все файлы из `README.md` и `docs/DECISIONS_AND_TBD.md`. Сопоставь их с `docs/PRODUCT_REQUIREMENTS.md`.
2. Составь `docs/TRACEABILITY_MATRIX.md` с матрицей: `requirement ID → related screen → API route → DB table → acceptance test → status`.
3. Проверь противоречия и риски схемы, особенно child PIN + подтверждение взрослым, права старшего брата/сестры, grade audit, приватность mood comment, баллы/двойные начисления, RLS-покрытие таблиц Supabase.
4. Составь `docs/ARCHITECTURE_DECISIONS_TO_APPROVE.md`: решения, которые реально требуют выбора владельца продукта, с рекомендацией и последствиями.
5. Сделай карту экранов (navigation map) для двух ролей и wireframe specs в Markdown. Отдельно выдели незавершённый визуальный стиль ребёнка (TBD) и цели/значки.
6. Составь список предположений по обработке данных, которые требуют правовой проверки целевых рынков (GDPR/COPPA и др.); не выдавай догадки за юридические факты.
7. Подготовь следующий ticket P0-03 с критериями приёмки и перечнем необходимых макетов. **Не переходи автоматически к Phase 1**.

Ответ строго в формате, указанном в `AGENTS.md`. Не использовать настоящие данные детей и не публиковать код/данные в сторонних сервисах.
